# 독립형 전산화번호 주소 찾기

ElecMap 페이지와 브라우저 자동화 없이 전산화번호로 좌표를 계산한 뒤 카카오 주소 API에서 지번 주소를 받습니다. Windows용 EXE는 GitHub Actions의 `Build independent address finder` 결과에서 `pole-address-independent-windows`를 다운로드하여 실행합니다. Python 설치는 필요 없습니다.

## 준비

1. 카카오 디벨로퍼스에서 앱을 만들고 REST API 키와 카카오맵 API 사용 설정을 준비합니다. 키는 프로그램 창에 입력하며 파일에 저장하지 않습니다.
2. `주소샘플.xlsx`를 컴퓨터에 두고, 프로그램의 **샘플 엑셀**에서 선택합니다.
3. 권역을 선택하고 전산화번호를 입력한 뒤 **주소 찾기**를 누릅니다. 조회 후 **주소 복사**를 누르면 번호와 좌표를 제외한 주소만 클립보드에 들어가며, 원하는 곳에 Ctrl+V로 붙여 넣을 수 있습니다. 여러 번호는 첫 열에 코드가 있는 입력 엑셀을 선택해 **엑셀 주소 입력**을 누릅니다.
4. 결과는 `_독립주소결과.xlsx`에 두 번째 열 주소, 세 번째 열 검토 상태, 네 번째와 다섯 번째 열 좌표로 저장합니다.

1권역(경기/충청)은 영상의 서로 다른 여섯 번호와 표시 좌표에서 오차 1m 이내로 검증했습니다. 강원 동부·강원 서부·부산울산은 샘플 주소 5개를 카카오 주소 API로 좌표화하여 권역 기준점을 맞춥니다. 주소가 가리키는 필지/건물 지점은 실제 전주 지점과 다를 수 있어 샘플의 중앙 오차가 70m 또는 최대 오차가 180m를 넘으면 해당 권역의 자동 주소 입력을 중단합니다. 이 기준을 통과하더라도 지번 경계에서는 다른 주소가 나올 수 있으므로 결과의 상태 열을 확인하세요.

권역 선택은 현재 샘플 파일의 네 묶음을 지원합니다. 다른 권역은 검증 자료가 확보된 뒤 추가할 수 있습니다. 카카오 API 이용 조건과 할당량은 사용자 계정의 설정을 따릅니다.
