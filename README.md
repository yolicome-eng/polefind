# PoleFind — ElecMap 주소 자동입력

Windows에서 Chrome이 설치되어 있어야 합니다. `polefind.exe`를 실행하고 첫 열에 전산화번호가 들어 있는 `.xlsx` 파일과 권역을 고른 다음 **검색 시작**을 누릅니다. 결과는 원본 옆 `_주소결과.xlsx`로 저장됩니다. 원본 엑셀은 그대로 보존합니다.

검색 화면의 광고 대기창에 **검색 시작**이 나타나면 프로그램이 버튼을 누르고, 지도 결과에 현재 전산화번호와 상세 주소가 함께 표시될 때만 두 번째 열에 주소를 기록합니다. 행마다 결과를 저장하므로 중간에 멈춰도 앞 행은 남습니다. 실패한 행에는 실패 이유를 쓰고 `_오류_행번호.png` 화면을 저장합니다. 그 화면과 실패한 번호를 전달하면 원인을 확인할 수 있습니다.

결과 엑셀을 Excel에서 열어 둔 상태에서는 저장할 수 없으므로 닫고 실행하세요. 광고 화면은 사이트 정책에 따라 달라질 수 있습니다. 실패 행을 자동으로 성공 처리하지 않습니다.

## 빌드

GitHub Actions의 **Build Windows EXE** 실행 결과에서 `polefind-windows`를 다운로드하여 압축 해제합니다. 소스에서 직접 빌드할 때는 `pip install -r requirements.txt pyinstaller` 후 `.github/workflows/build-exe.yml`의 빌드 명령을 실행합니다.
